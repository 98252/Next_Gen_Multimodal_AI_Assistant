# 🏔️ Nepal-GPT | Next-Gen Multimodal AI Assistant

A modern, dark-themed AI chatbot, multimodal vision analysis, document intelligence, and visual analytics web application powered by **Google Gemini** with real-time streaming, **Chat Pinning & Renaming**, **Multimodal Image Recognition**, **File Attachment System**, **7 Dedicated AI Modes**, interactive **Chart Generation** (Chart.js), and multilingual intelligence (English & Nepali / नेपाली).

---

## 🛠️ Quick Start

### 1. Launch the Server

**PowerShell**:
```powershell
.\.venv\Scripts\python.exe app.py
```

**Access Web UI**:
👉 Open **[http://localhost:5050](http://localhost:5050)** in your browser.

---

## 📌 Chat Management & History

| Feature | Description |
| :--- | :--- |
| **📌 Pin / Unpin Chats** | Pin your important chat sessions to the top into a dedicated **`📌 PINNED`** group. |
| **✏️ Rename Chat** | Click the **`✏️` Edit icon** on any chat in the sidebar or click the chat title in the top navbar to rename in place (`Enter` to save). |
| **🗑️ Delete Session** | Cleanly remove individual chats or click `Clear All` to reset history. |
| **🕒 Smart Date Grouping** | Automatically organizes past conversations by **PINNED**, **TODAY**, **YESTERDAY**, **PREVIOUS 7 DAYS**, and **OLDER**. |
| **🔍 Real-Time Search** | Instant filter across your entire chat history. |

## 🖼️ Multimodal Vision & Attachments

- **🖼️ Image Attachment**: Upload PNG, JPG, WEBP, GIF, SVG images for Gemini Vision inspection.
- **📁 File System Attachments**: Attach `.txt`, `.csv`, `.json`, `.md`, `.pdf`, `.py`, `.js` files.
- **📋 Clipboard Paste (`Ctrl+V`)**: Instant paste of screenshots & copied images.
- **☁️ Drag & Drop**: Drop files and images anywhere onto the workspace.
